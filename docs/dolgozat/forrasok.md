# Források

A dolgozat forrásai. Formátum: `- kulcs: hivatkozás szövege (Utolsó megtekintés: ÉÉÉÉ. HH. NN.)`.
A szövegben `[@kulcs]` hivatkozik rájuk; a sorszámot a generálás az első
előfordulás sorrendjében adja. Minden forrást megnyitás után, ellenőrizve
veszünk fel; az elérési dátum a tényleges megtekintés napja.
